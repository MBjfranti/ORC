## Documented gaps

Things I looked for and could **not** find published anywhere:

1. **The Secret Chords combination list.** Not in any of the 43 help articles, not in firmware
   notes, not in any review. Appears intentionally undocumented.
2. **The complete 60-preset name list.** Only 15 names are public (5 lead, 5 bass, 5 drums).
3. **The complete 20-beat name list.** Only 5 are public.
4. **The 11 Pattern-mode rhythms.**
5. **Exact FX parameter mapping** on the FX encoder.
6. **Whether `Sus` is sus4 or sus2.**
7. **Key Mode behavior on the 5 non-diatonic keys.**
8. **Natural vs harmonic minor** in Key Mode.
9. **Full firmware changelogs for v3.04 → v3.84** — the updater page renders only the latest
   version's notes without interactive clicks; older entries were not retrievable.
10. **Whether MIDI clock exists** — one review says no; official docs are silent.

None of these block the build. Each is flagged in the relevant file as a design decision for us
to make deliberately rather than a spec to match.

## The Operation Manual (v4.1, March 2026) — the authoritative source

`Telepathic Instruments - Orchid Operation Manual.pdf` in the project root, extracted to
[`90-operation-manual-v4.1.txt`](90-operation-manual-v4.1.txt). 29 pages. Extract it with
PyMuPDF — a hand-rolled parser stalls because the fonts are per-subset single-byte CMaps whose
codes collide, so merging them yields garbage:

```python
import fitz
d = fitz.open('Telepathic Instruments - Orchid Operation Manual.pdf')
text = ''.join(p.get_text('text') for p in d)
```

**It also contains screen mock-ups**, which are the only direct evidence of what the display
actually draws. Extract with `page.get_images(full=True)`; the 640×640 images are single-value
screens and the wide ones on p.9 are the chord-notation plates.

What the mock-ups establish, none of which was inferable from the support articles:

- The status bar is **inverted** — a white bar with black text across the top, key on the left
  (`Key: C`), battery on the right, transposition top-right.
- A value glance is an **enormous number with a small label beneath it**: `05` over `Reverb`,
  `20` over `Sound`, `+01` over `Transpose`.
- Chords print the triad at full size and the extensions **raised and small at the top right**:
  `C⁷`, `Cᴹ⁷`, `Cm⁷`, `Cdim⁷`, `Csus⁷`, `Cmᴹ⁷`.

Sections that specify behaviour the support articles omit entirely: §7.3 Perform Lock,
§8.3 **FX Lock**, §9.4 **Transposition**, §6.1–6.5 the chord-notation framework, §4.2 volume
ranges and the battery check on the Volume press.
